─── New: src/components/sections/HeroLiveCaptureSection.tsx ──────────────────

Two-column hero section for the "live capture" concept. Left column carries
the headline, tagline, and primary/secondary CTA buttons. Right column renders
an animated phone mockup overlaid with a live event status circle.

Schema fields:
  eyebrow, headline, subheading         — localizedString
  primaryCtaLabel, primaryCtaHref       — localizedString / string
  secondaryCtaLabel, secondaryCtaHref   — localizedString / string
  phoneMedia                            — image asset

Both CTA fields are optional. CTAs render only when their label is set.
Section is animation-aware: entrance via SlideUp with motion tokens from DS.

─── New: src/components/sections/HeroLensSection.tsx ─────────────────────────

Story-driven two-column hero for the "filming a live event" concept. Left
column is a large-format image (the "lens" — footage or event imagery). Right
column carries headline, description, and CTA pair.

Schema fields mirror HeroLiveCaptureSection with an added image field for the
left-column visual. Designed for event-adjacent or product landing contexts
where the visual is the primary hook.
