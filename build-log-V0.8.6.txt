V0.8.6 — Livener Events Architecture Refactor
Build date: 2026-06-18
Branch: dev

─── Summary ────────────────────────────────────────────────────────────────────

Full architectural separation of three concepts that were previously conflated:
1. Live Page (/live)    — editorial hero + Cloudflare video + featured events
2. Events Page (/events) — collection listing with all events
3. Event Detail (/events/[slug]) — existing route, verified and fixed

─── New Sanity document types ──────────────────────────────────────────────────

livePageType
  Fields: projectSlug, heroTitle, heroSubtitle, betaNotice, introText,
          cloudflareVideoId (string, not iframe HTML), featuredEvents (ref array),
          seoTitle, seoDescription

eventsPageType
  Fields: projectSlug, heroTitle, heroSubtitle, introText, heroImage, seoTitle, seoDescription

─── Removed ────────────────────────────────────────────────────────────────────

- livePageHeadline / livePageSubheadline / livePageBetaNotice from siteConfigType
- 'live' group from siteConfigType
- videoEmbedUrl from eventType (added in V0.8.5, superseded by cloudflareVideoId on livePage)
