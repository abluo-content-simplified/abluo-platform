─── Changes ──────────────────────────────────────────────────────────────────

Homepage Routing — abluo.app
  - Modified: src/proxy.ts
      Added 'abluo.app' → 'abluo-the-tiny-cms' to domainMap.
      Added 'abluo-the-tiny-cms' → 'en' to resolveDefaultLocale().
      abluo.app now resolves to the abluo-the-tiny-cms tenant and renders
      the home page document (projectSlug: "abluo") via the standard
      section renderer pipeline. All three production domains are now
      fully routed: livener.net, studiomartegani.com, abluo.app.

Home Page Uniqueness Validation
  - Modified: src/lib/sanity/schema.ts
      Added async custom validation rule to the pageType field on the
      page document type. When pageType is set to "home", the rule queries
      Sanity to check whether another page with pageType == "home" already
      exists for the same projectSlug (excluding the current document's
      draft and published versions). If a duplicate is found, Studio
      blocks the change with: "A home page already exists for this project.
      Only one home page is allowed per project."

─── Routing Architecture Audit ──────────────────────────────────────────────

Full end-to-end routing verified for all projects:

  livener.net         → livener → livener-main → homePage ✅
  studiomartegani.com → studiomartegani → studiomartegani-main → homePage ✅
  abluo.app           → abluo-the-tiny-cms → abluo → homePage ✅ (fixed this release)

Root cause of abluo.app 404 (pre-fix):
  abluo.app was not in proxy.ts domainMap → fell to intlMiddleware →
  redirected / to /en → no [locale]/page.tsx handler → 404.
  The Sanity home page document for projectSlug "abluo" already existed;
  only the two proxy.ts entries were missing.
